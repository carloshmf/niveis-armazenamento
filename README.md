Olá! Este repositório armazena a atividade prática de **Controle de Níveis de Água**, desenvolvida para o curso técnico em Desenvolvimento de Sistemas.

## 🎯 Sobre o Projeto
O projeto consiste em um sistema executado no terminal que simula o monitoramento de um reservatório de água dividido em cinco níveis. O objetivo principal foi aplicar conceitos fundamentais de programação e estilização visual de logs no console.

## ✨ O que foi aplicado
- **Estruturas de Dados:** Organização dos níveis e situações utilizando listas em Python.
- **Modularização:** Criação de funções dedicadas para o tratamento e exibição dos dados.
- **Manipulação de Bibliotecas:** Uso da biblioteca externa `colorama` para colorir dinamicamente os alertas de acordo com o nível de risco (do crítico ao alerta).
- **Boas Práticas:** Restauração automática do estilo padrão do terminal após a exibição das mensagens.
